# AR.js Marker MVP

A minimal static WebAR demo using AR.js and A-Frame. It opens the phone camera, tracks the Hiro marker, and places a small glTF duck model on top of the marker.

## Try It

1. Open the published GitHub Pages URL on a phone.
2. Allow camera access.
3. Point the camera at the Hiro marker.

Hiro marker:
https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png

## Local Preview

Because camera access requires a secure context on phones, test the full AR flow from the published HTTPS GitHub Pages link. A local desktop preview can still confirm that the page loads.

## Publishing

This repo is ready for GitHub Pages. Push it to GitHub, then enable Pages from the repository settings using the `main` branch and `/root` folder.
